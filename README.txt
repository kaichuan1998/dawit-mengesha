PREVIEW AND EDIT
1. Open index.html in a browser. No software installation or build is needed.
2. Open index.html in a plain-text or code editor to change the text.
   Search for "EDIT:" to find each editable section.
3. Replace placeholder paragraphs with Dawit's confirmed information. Keep the
   section IDs so the navigation links continue to work. Remove the profile
   notice when the profile is complete. Update the page description as well.
4. Add links only after you know the correct destination. To add an email link,
   use href="mailto:..." with Dawit's confirmed email address. For an optional
   CV or portrait, add Dawit's actual file and reference it with a relative path,
   such as assets/cv.pdf or assets/portrait.jpg. No CV or portrait is included.
5. Reload the browser to see your changes. The page works without JavaScript.

PUBLISH THROUGH THE GITHUB WEBSITE
1. Sign in to the chosen GitHub account and create a new repository named
   dawit-mengesha.github.io. Use a public repository for GitHub Free.
   This is a separate repository from the existing personal homepage.
2. Unzip dawit-mengesha.github.io.zip. Open the extracted folder and upload its
   CONTENTS to the repository root. Do not upload the ZIP, and do not put an extra
   dawit-mengesha.github.io folder inside the repository. The file index.html
   must appear at the top level, beside style.css.
3. Commit the uploaded files to main. Include .nojekyll if your file picker shows
   hidden files. If it does not, use Add file > Create new file on GitHub to create
   .nojekyll at the root; a blank line is sufficient. The .gitignore file is optional.
4. Open Settings > Pages. Under Build and deployment, choose Deploy from a branch.
   Choose main and /(root), then Save.
5. Wait for the Pages deployment to finish. Open the published address shown in
   Settings > Pages, and check the section links and appearance on your phone.

If publication fails, check the repository's Actions tab and Pages settings.
Confirm index.html is lowercase and at the selected publishing root, and that
an administrator with a verified GitHub email address has pushed the files.
For unstyled pages, confirm style.css was uploaded beside index.html.
